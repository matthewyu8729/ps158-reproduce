    02 / SET THE INCENTIVES

    What counts as success?

    The real goal is to finish with high trust. The reward rule is yours to change.

    Original rule: click points plus any trust incentives you set below.

    Switching options or editing numbers resets the agent, learning curve, and current game. Trust stops at high and low; hitting a boundary gives no trust-change reward.

    A deliberately small world: 15 states

    State = last post (none, news, sports, outrage, local) × trust (low, medium, high). Trust is a hidden three-level score: 0, 1, or 2. Outrage lowers it by 1; local raises it by 1, regardless of clicks.

    The agent can observe trust; the human can reveal it. Round number is excluded from the state, so this small table cannot learn a special final-round strategy. The 20-round cutoff is tracked separately.
